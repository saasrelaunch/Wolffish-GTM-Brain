# Template library

Shape, not content. Each template holds the sections, the order, the fields to fill and the
guardrail line, so a hurried operator fills a known structure instead of inventing one.

There is one template per channel in the mix and no more. A template for a channel this
go-to-market refuses would be an invitation to produce for it.

| Template | Use for | Channel |
|---|---|---|
| `founder-post.md` | Bilingual organic post, one instrument or one number per post | Founder writing, ~15% of pipeline |
| `warm-introduction.md` | The forwardable paragraph and the ask to the sponsor | Warm introduction, ~30% |
| `event-presence.md` | Speaking abstract, stand conversation, same-week follow-up | Events, ~35% |
| `messaging-followup.md` | The message sent after an introduction has landed | Messaging apps, ~10% |
| `security-call.md` | The pivotal call agenda, the disqualifier list, the artefacts | All channels converge here |
| `one-pager.md` | Bilingual leave-behind, one audience per version | Events and introductions |
| `landed-cost-email.md` | The breakdown that reaches a finance director who was not in the room | Owned and follow-up |
| `compliance-evidence-section.md` | One control section of the Compliance Evidence Pack | Evaluation stage |
| `partner-co-sell-brief.md` | The proposition put to a system integrator or a cloud partner | Partner co-sell, ~10% |
| `tender-response.md` | A structured response to an Etimad or entity tender | Public tender, year two |
| `site-page.md` | A page on the bilingual owned site, Arabic first | Owned, underpins all |

## Rules that apply to every template here

One audience per asset. A security officer and a finance director are never addressed in the
same document, because the sentence that reassures one alarms the other.

Every capability mention carries its status flag in the same sentence, checked against
`../rules/feature-status.md`.

Every price mention carries all three lines and the words landed cost, checked against
`../reference/pricing-model.md`.

Arabic is the headline and English is the subhead in any Arabic-first surface, and the Arabic is
written natively rather than translated.

Guardrail: before shipping anything built from a template here, read `../rules/writing-rules.md`,
`../rules/do-not-say.md` and `../rules/feature-status.md`, then run `../ops/QA-checklist.md`.
