## Wolffish Cloud go-to-market

Marketing, sales and product copy in this repository is governed by the Wolffish Cloud brain at
`~/gtm/Wolffish-GTM-Brain`. Read its `AGENTS.md`, then `rules/do-not-say.md` and
`rules/feature-status.md`, before suggesting any customer-facing text, including strings in code,
documentation, commit messages and release notes. Change the path if the brain is checked out
elsewhere.

Four rules override any suggestion you would otherwise make.

1. A capability that is not flagged SHIPPED is never written in the present tense.
2. A number, customer name, quote or metric that is not in `ops/copy-bank.md` is never written at
   all. There is no reference customer.
3. A price is never written as the seat fee alone. All three lines, or none.
4. Every draft passes `ops/QA-checklist.md` before it is offered.

Audiences, never blended: the security officer, the finance director, and the partner-reached
institutions of ICP 2.
