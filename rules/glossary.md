# Glossary, canonical vocabulary

last_reviewed: 2026-09-04

Checked on every noun. A term earns a row when getting it wrong would be visibly wrong to a Saudi
enterprise buyer. Full context in `../context/Wolffish_GTM_Master_Context.md` Section 2.

## Canonical terms

| Term | Rule |
|---|---|
| **Wolffish Cloud** | The product name. Both words, both capitalised, every time. |
| **Wolffish** | The company. Correct alone when the subject is the company rather than the product. |
| **in-perimeter** | Where the work happens. Hyphenated, lower case except at the start of a sentence. |
| **capability** | The unit of function, and the unit the allowance is denominated in. |
| **seat** | One employee with an agent. The billing unit. |
| **landed cost** | All three price lines including the customer's own inference and infrastructure. |
| **pass-through** | The inference and infrastructure line, billed by the customer's own providers at zero Wolffish margin. |
| **capability allowance** | The quarterly bound on ongoing capability development. Proposed, not yet contracted. |
| **deployment scope ladder** | The three deployment tiers: Pilot, Standard, Complex. |
| **security call** | The first substantive meeting. Not a discovery call, not a demo. |
| **pilot cohort** | Ten seats, three weeks, one named workflow, inside the customer's perimeter. Paid. |
| **Compliance Evidence Pack** | The regulatory document set. Capitalised, it is a named artefact. |
| **Agent Exposure and Spend Audit** | The one-week founder-led diagnostic. Capitalised. |
| **Kingdom AI Exposure Scorecard** | The self-assessment lead magnet. Capitalised. |
| **zero-retention endpoint** | The inference endpoint on the customer's own account. |
| **the Kingdom** | Saudi Arabia, in running prose. Correct and preferred over repeating the full name. |

## Banned near-synonyms

| Do not write | Write instead | Why |
|---|---|---|
| on-premise, on-prem | in-perimeter | Implies a server room. Agents run on employee laptops. |
| private cloud | in-perimeter | Implies a tenant inside a vendor's cloud, which is the opposite of the architecture. |
| feature | capability | A feature invites a catalogue comparison Wolffish loses. |
| user, licence | seat | Seat is the billing unit and the one the customer's finance function recognises. |
| chatbot, assistant, copilot | agent | The product is not a chat surface, and two of these are competitor product names. |
| sovereign AI | in-perimeter, or Saudi-hosted | Belongs to the national champion. Taking it starts a fight Wolffish loses. |
| AI spend governance | cost forecastability | The rejected category. See the decision log. |
| on-device AI | agents execute on the employee's machine | Suggests local model inference, which is not what happens. |
| SaaS, subscription software | deployed platform, or platform seat | Wolffish is not multi-tenant software. |

## The distinction that must never blur

**Data residency** is a contractual commitment about how a vendor handles data after it has been
received. Every competitor offers it, including the ones with no presence in the Kingdom.

**No vendor-side data path** means the vendor never receives the data at all. There is no route by
which a prompt, a file or an output reaches Wolffish.

Wolffish claims the second. Claiming the first is both weaker and, in front of a security officer,
an invitation to be compared with vendors who say the same thing and hold certifications Wolffish
does not. Every cost, compliance and architecture claim in this brain hinges on keeping these two
apart.
