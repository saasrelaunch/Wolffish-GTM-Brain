# Pre-ship QA checklist

Run every item before returning anything customer-facing. Each item is answerable yes or no by
looking at the draft. If an item needs judgement, it is not a check yet, it is guidance, and it
belongs in `../rules/writing-rules.md`.

Cheapest checks first.

## 1. Writing mechanics

- [ ] No em dashes anywhere.
- [ ] None of the banned words appear: leverage, unlock, seamless, robust, streamline, cutting-edge, empower, revolutionary, game-changing, synergy, best-in-class, world-class, turnkey, frictionless.
- [ ] Paragraphs are one to three sentences.
- [ ] Specific numbers and named capabilities instead of adjectives.
- [ ] No stacked adjectives, no hype, no urgency that is not a real date.
- [ ] Currency written as SAR with a space. Value-added tax treatment stated wherever a price appears.

## 2. Channel

- [ ] This is a channel this go-to-market produces for.
- [ ] It is not automated outreach sequencing, volume cold email, or paid social.
- [ ] If the request was for a refused channel, the draft declines, names the reason, and offers the in-scope alternative.

## 3. Claims

- [ ] Every capability mentioned carries its status flag in the same sentence.
- [ ] No capability flagged IN BUILD or ROADMAP is described in the present tense.
- [ ] Nothing unshipped is demonstrated, recorded or narrated as though a customer could do it today.
- [ ] No customer name, logo, quote, count, case study or outcome metric appears anywhere.
- [ ] No certification is claimed or implied.
- [ ] Every superlative has been checked against `../rules/do-not-say.md` and appears in its narrowed form.
- [ ] Every conditional claim names its condition in the same sentence.
- [ ] Any cost comparison states landed cost on both sides and names the pass-through line.
- [ ] The phrase "no new invoice" does not appear, because the capability allowance is not yet contracted.
- [ ] Where Microsoft's assistant is cheaper, the draft says so first rather than avoiding it.

## 4. Naming and strategy

- [ ] Canonical vocabulary from `../rules/glossary.md` is used throughout.
- [ ] Nothing is called on-premise, private cloud, a feature, a user, a chatbot, an assistant or sovereign AI.
- [ ] The category is stated as an in-perimeter agentic workforce platform, never as spend governance.
- [ ] Data residency and no vendor-side data path are not blurred.
- [ ] No framing contradicts a decision recorded in `decisions.md`.
- [ ] The national champion is neutralised in one sentence, not argued with.

## 5. Audience and stage

- [ ] Exactly one audience. ICP 1 and ICP 2 are not blended.
- [ ] The pillar matches the chair: perimeter for the security officer, cost for finance, capability for the chief executive, economics against the integrator for the technology lead.
- [ ] The asset matches its funnel stage in `../reference/customer-journey.md`.
- [ ] Any seat count referenced clears the 200-seat floor.

## 6. Bilingual

- [ ] Both languages are present.
- [ ] In an Arabic-first channel the Arabic is the headline and the English is the subhead.
- [ ] The Arabic reads as written rather than translated.
- [ ] Right-to-left layout and mixed numerals have been checked on a real device, for anything rendered.

## 7. Voice

- [ ] It reads like the matching file in `../examples/`.
- [ ] A limitation is named somewhere, unprompted.
- [ ] Approved lines from `copy-bank.md` are used verbatim rather than rewritten.
- [ ] Nothing in the draft required a fact the brain does not hold. If it did, that gap is flagged rather than filled.

## After shipping

- [ ] The asset is filed in `../pages/` if it is long-form, and listed in `asset-index.md` if it is a live surface.
- [ ] Anything the work taught you is logged in `signal-log.md`.
- [ ] Any reusable line is proposed for `copy-bank.md`.
